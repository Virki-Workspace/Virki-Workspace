### Virki

I do practical research around resilience and digital resilience, open source,
and automation with public values.

Virki is the workshop behind it: a self-hosted digital workplace where I run the
everyday tools (mail, files, calendars, code, tasks, identity, home automation)
on open-source software, on servers I control. What guides it: software that
serves the people who use it rather than harvesting them, data kept under our
own keys, and a preference for tools we can host ourselves over tools we rent.

Occasionally I share a note or fix I think others can use.

*Strong walls, open minds.*
